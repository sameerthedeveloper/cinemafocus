## Where to start

- Building UI: read [design/DESIGN_SYSTEM.md](design/DESIGN_SYSTEM.md), then [design/design.md](design/design.md).
- Before a launch or SEO change: [seo/SEO_LAUNCH_CHECKLIST.md](seo/SEO_LAUNCH_CHECKLIST.md).
- Writing site content: [content/CONTENT_STRATEGY.md](content/CONTENT_STRATEGY.md).
- Infrastructure: `../infra/` (backend) and `../scripts/` (backup, restore, imports).

## Adding docs

Put each document in the folder that matches its topic, use `UPPER_SNAKE.md` for checklists and
reports and short lowercase names for guides, and link it from this page.
